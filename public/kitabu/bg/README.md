# Background media

Put the real-nature background here (not committed yet):

- `forest.jpg` — a photo (bamboo forest, river or mountains), about 1600 px wide, under 400 KB. Shown on every phone, with a slow zoom.
- `forest.mp4` — optional looping video of the same scene, 10–20 s, H.264, 720p, under 8 MB. Played only when the phone is online, not in data-saver mode and not set to reduce motion; otherwise the photo is used.

Free sources with no attribution required: pexels.com or pixabay.com (search "bamboo forest", "river mountain").
If neither file exists the app draws its own illustrated scene.
